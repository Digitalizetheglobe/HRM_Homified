Laravel HRM Deployment Guide (CyberPanel + OpenLiteSpeed)

Developer PC

1.  Latest code GitHub var push kara.

    git add .
    git commit -m "Your changes"
    git push origin main

------------------------------------------------------------------------


    cd /home/hrm.homifiedconsultants.com/public_html

------------------------------------------------------------------------

1. Latest Code Pull

    git pull origin main

------------------------------------------------------------------------

2. Composer (ONLY if composer.json or composer.lock changed)

Use PHP 8.2:

    /usr/local/lsws/lsphp82/bin/php /usr/bin/composer install --no-dev --optimize-autoloader

If composer files did NOT change, skip this step.

-----------------------------------------------------------------------

------------------------------------------------------------------------

4. Clear & Rebuild Laravel Cache

    php artisan optimize:clear
    php artisan config:cache
    php artisan route:cache
    php artisan view:cache


    chown -R hrmho2861:hrmho2861 storage bootstrap/cache
    chmod -R 775 storage bootstrap/cache

------------------------------------------------------------------------

6. Restart OpenLiteSpeed (Optional but safe)

    systemctl restart lsws

------------------------------------------------------------------------

7. Verify

Open:

https://hrm.homifiedconsultants.com

Check: - Login page opens - No 500 error - New feature visible -
Storage/uploads working

------------------------------------------------------------------------

Quick Deployment

Normal PHP changes:

git pull origin main php artisan optimize:clear php artisan config:cache
systemctl restart lsws

------------------------------------------------------------------------

Composer changed:

git pull origin main /usr/local/lsws/lsphp82/bin/php /usr/bin/composer
install –no-dev –optimize-autoloader php artisan optimize:clear
systemctl restart lsws

------------------------------------------------------------------------

Migration added:

git pull origin main /usr/local/lsws/lsphp82/bin/php /usr/bin/composer
install –no-dev –optimize-autoloader php artisan migrate –force php
artisan optimize:clear systemctl restart lsws

------------------------------------------------------------------------

Important: - Never edit .env during normal deployment. - Take database
backup before major updates. - If git pull reports conflicts, stop and
resolve before continuing.
